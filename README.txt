# 🛍️ Smart E-commerce Automation Platform

An AI-powered e-commerce automation platform that streamlines the online shopping experience by integrating intelligent customer support with workflow automation.

This project combines a responsive web application with **n8n** to automate order processing, inventory management, customer communication, and real-time notifications. Customers can browse products, place orders, and interact with an AI chatbot, while the backend automatically stores orders, updates inventory, and notifies the store owner.

---

## 🚀 Features

- 🤖 AI-powered chatbot using Google Gemini
- 🛒 Responsive online store
- 📦 Automated order processing
- 📊 Automatic order storage in Google Sheets
- 📉 Inventory monitoring
- 📧 Email notifications for low-stock products
- 📱 Telegram notifications for new orders
- ⚡ End-to-end workflow automation using n8n
- 🌐 User-friendly shopping experience

## 🔄 Workflow Overview

The automation workflow performs the following tasks:

- Receives customer orders through Webhooks.
- Processes order details automatically.
- Stores orders in Google Sheets.
- Monitors product inventory.
- Sends Telegram notifications for new orders.
- Sends email alerts when product stock becomes low.
- Provides AI-powered customer support using Google Gemini.
